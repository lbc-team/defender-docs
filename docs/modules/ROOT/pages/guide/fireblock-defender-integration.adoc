:page-title: Defender 中的 Fireblocks 集成

您可以直接从 Defender 向 Fireblocks 提交交易。Fireblocks 是一种强大的资产管理解决方案，它利用多方计算来保护所有资金库操作，从而确保更高的安全性和效率。

[[pre-requisites]]
== 前提条件

* 如果您想在 Defender 中使用 Fireblocks，您可以联系 OZ 团队，为您的帐户启用 Fireblocks 集成。

[[generate-csr-file]]
== 1. 生成 CSR 文件
. 要使用此功能，请导航到*设置*页面，然后单击侧栏中的*审批流程*。如果您的帐户已启用 Fireblocks 集成，请转到*集成*选项卡，该选项卡位于*所有审批流程*选项卡旁边。
+
image::guide-fireblocks-integration-tab.png[集成选项卡]
+
. 点击*为 Fireblocks 生成新的 API 密钥*。在这里，您需要生成一个证书签名请求 (CSR)，该请求将在 Fireblocks 平台中使用，以启用此功能并创建 API 密钥。
+
image::guide-fireblocks-csr-modal.png[CSR 生成模态框]
这将触发 Defender 生成一个公钥/私钥对。然后生成 CSR 并使用私钥签名，并安全地存储，以防止泄露。

[[create-fireblocks-api-user]]
== 2. 创建 Fireblocks API 用户
. 首先，您需要在创建新的 API 用户时，在 Fireblocks UI 中导入 CSR。请注意，API 用户将需要任何_至少_可以启动交易的角色，例如，签名者。
+
image::guide-fireblocks-add-user.png[创建 API 用户, width=400]
+
. 创建 API 用户并经 Fireblocks 工作区所有者批准后，复制 Fireblocks API 密钥并导航到 Fireblocks API 密钥页面。您应该会看到一个不完整的 API 密钥设置，您可以编辑并使用 Fireblocks API 密钥完成该设置。请注意，除非您完成设置或删除之前不完整的设置，否则您将无法生成新的 CSR 文件。
+
image::guide-fireblocks-api-key.png[API 密钥已生成]
+


[[setup-defender-integration]]
== 3. 将 Fireblocks 与 Defender 连接
. 首先，导航到*设置*页面，然后单击侧栏中的*审批流程*，然后导航到*集成*选项卡。在这里，单击*从 Fireblocks 粘贴 API 密钥*。
+
image::guide-fireblock-paste-api-key.png[插入 API 密钥 Defender]
+
. 插入 Fireblocks API 密钥。
+
image::guide-fireblocks-edit-api-key.png[插入 API 密钥, width=600]
+
NOTE: 要通过 Defender 将交易提交到 Fireblocks，请确保在 Fireblocks 中设置了正确的权限，例如相关的白名单地址和交易访问策略 (TAP)。 例如，您可能需要将您希望与之交互的合约地址列入白名单，并确保新创建的 API 用户被允许与相关的帐户和资金库进行交互（在 TAP 中定义）。

[[create-approval-process]]
== 4. 创建审批流程

[[create-approval-process-automatic]]
=== 从列表中选择一个 Fireblocks 钱包
您可以通过仅提供 Fireblocks API 密钥从可用钱包列表中选择一个 Fireblocks 钱包。我们将尝试从 Fireblocks 获取可用资金库和钱包的列表。

image::guide-fireblocks-approval-process-automatic.png[创建 Defender 审批流程]

[[create-approval-process-manual]]
=== 手动添加 Fireblocks 钱包
在一些罕见的情况下，您可能无法在从 Fireblocks 自动获取的列表中看到您的钱包。 在这种情况下，您可以选择“手动”选项并手动输入所需的信息。

image::guide-fireblocks-approval-process-manual.png[创建 Defender 审批流程]

要获取您的 **Vault ID**，请前往 Fireblocks 控制台，单击您感兴趣的资金库，然后从 URL 中复制 ID（最后一个数字）。

image::guide-fireblocks-vault-id.png[Vault ID]

要获取您的 **Asset Wallet Address**，请前往 Fireblocks 控制台，单击您感兴趣的资产，然后复制地址（以 0x 开头）。

image::guide-fireblocks-asset-wallet-address.png[资产钱包地址]


[[approve-reject-transaction]]
== 5. 批准或拒绝交易
请注意，Defender 不允许您从 UI 批准或拒绝交易。这只能通过 Fireblocks 移动应用程序或控制台实现。
