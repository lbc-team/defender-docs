:page-title: 升级 Actions 依赖

Actions 必须使用最新的 Node.js 运行时和依赖版本进行更新，以确保它们在最新的安全环境中运行。有时，Node.js 和依赖版本会在 Defender 上被弃用，这意味着在这些 Node.js 版本（和相关依赖）上运行的 Actions 必须升级到最新的版本，以确保它们继续按预期运行。

[[upgrade-process]]
== 升级过程

当 Node.js 出现重大版本弃用时，Defender 团队会通知用户有关此事件，并设定将 actions 升级到最新依赖版本的时间限制。如果在截止日期前未采取任何措施，Defender 会代表用户自动升级 actions。

WARNING: 我们鼓励用户自己完成升级过程，因为自动升级可能会在依赖项中引入重大更改。

[[how-to-upgrade-actions-runtimes]]
== 如何升级 Actions 运行时

1. 检查 Action 的 https://docs.openzeppelin.com/defender/module/actions#environment[依赖项最新版本, window=_blank]，并在您的 Action 代码中搜索任何重大更改。
2. 进行任何必要的代码更改。
3. 测试 Action 代码。一个安全的方法是：
  a. 使用目标依赖版本创建一个具有相同代码的新 Action，并运行它以验证它是否按预期工作。
  b. 如果您的 action 使用 https://docs.openzeppelin.com/defender/sdk[defender-sdk, window=_blank]（或任何其他 Defender 遗留包）发送 relayer 交易，请通过将测试网 relayer 连接到您的 action 来验证它是否有效。
4. 验证代码和依赖项兼容后，将 Action 依赖项升级到最新版本。
