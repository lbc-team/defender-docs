[[remix-plugin]]
= Remix 插件

从 https://remix.ethereum.org/[Remix IDE, window=_blank] 编码和编译合约时，你可以使用 Defender 插件，通过配置 xref:module/deploy.adoc[部署环境] 并使用审批流程作为部署者来部署你的合约。

[[installation]]
== 安装

1. 前往 https://remix.ethereum.org/[Remix IDE, window=_blank] 并点击插件管理器（左下角）。
2. 从模块列表中搜索 *Defender Deploy*，并点击“激活”。
3. 应该在左侧导航栏中显示一个带有 OpenZeppelin 图标的新标签。

image::remix-plugin-install.png[安装 Defender Remix 插件,330,500]

[[usage]]
== 用法

[[api-key-generation]]
=== API 密钥生成
在你的 Defender 仪表盘中，进入 *设置 -> API 密钥* 并点击 *创建 API 密钥*，你只需要 _Manage Deployments_ 权限。

WARNING: 我们还建议为 API 密钥设置过期时间，因为它将从外部站点使用。

image::remix-plugin-api-key.png[Defender Remix 插件 Api 密钥, 400, 400]

[[deploying-from-remix]]
=== 从 Remix 部署

前往 Remix IDE 站点，并打开 Defender 插件（参见安装步骤）。

[[setup]]
==== 设置
设置你的 *API 密钥* 和 *API Secret* 并按下 “认证”。如果密钥有效，你应该在右侧看到一个绿色勾号，表明你已成功通过身份验证，同时 Remix 终端中会显示一条消息。

image::remix-plugin-setup.png[Defender Remix 插件设置]

[[network]]
==== 网络
选择任何支持的网络。 这也包括在你的租户中配置的私有和 Fork 网络。

image::remix-plugin-network.png[Defender Remix 插件网络]

[[approval-process]]
==== 审批流程
这里你有 3 个选项：

- 从为所选网络配置的 *部署环境* 中选择现有的审批流程。

NOTE: 如果你在所选网络中已存在部署环境，则这是唯一允许的选项。

- 如果所选网络不存在 *部署环境*，则可以创建一个新的。

NOTE: 如果要创建的审批流程是一个 Relayer，则 API 密钥必须包含 _Manage Relayers_ 权限。

- 此外，你可以使用 Remix 中的 *注入的 provider*（浏览器钱包）来部署合约，这将在部署合约后在后台创建一个 Defender *部署环境*。

image::remix-plugin-approval-process.png[Defender Remix 插件审批流程]

[[deploy]]
==== 部署
你应该看到最新的已编译合约以及构造函数输入。

NOTE: 如果你没有看到它，请再次编译目标合同，Defender 插件应检测到编译并显示构造函数输入。

WARNING: 尚未完全支持可升级合约。 此操作只会部署实现合约，而不会进行初始化。 为了安全升级，我们强烈建议使用 https://github.com/OpenZeppelin/openzeppelin-upgrades[Upgrades Package, window=_blank]。

image::remix-plugin-deploy.png[Defender Remix 插件部署]

[[deterministic-deployments]]
==== 确定性部署

Defender Deploy 支持使用 `salt` 值，以使用 `create2` 创建到确定性地址的部署。单击 `Deterministic` 复选框并将 salt 字段设置为任何任意值。

image::remix-plugin-deploy-deterministic.png[Defender Remix 插件部署确定性]

[[further-steps]]
==== 后续步骤

将合约部署提交到 Defender 后，在某些情况下，你需要从 Defender 仪表板完成部署，你应该看到一个绿色横幅，指示合约已提交，并且有一个指向 Defender 中部署的链接。

image::remix-plugin-deploy-completed.png[Defender Remix 插件部署已完成]
