[[Integrations]]
= 集成

Defender 与您现有的工具和工作流程无缝集成，因此您可以在整个安全开发生命周期中轻松保护您的项目。

[[sdk]]
== SDK 插件
- https://hardhat.org/[*Hardhat*, window=_blank]: 通过 Defender 对您的 Hardhat 项目进行编码、部署和升级。
- https://getfoundry.sh/[*Foundry*, window=_blank]: 使用 Defender 支持对您的 Foundry 项目进行编码。

[[ide]]
== IDE
- https://remix.ethereum.org/[*Remix*, window=_blank]: 通过 Defender Remix 插件，使用 Defender 部署环境来部署您的 Remix 合约。

[[libraries]]
== 库
- https://www.openzeppelin.com/contracts[*OpenZeppelin Contracts*, window=_blank]: 通过内置的安全性和性能来加速您的智能合约开发。

[[continous-integration]]
== 持续集成
- xref:module/code.adoc[*GitHub*]: 安装代码检查器，以最大限度地提高每个项目 PR 的安全性。
- xref:dac.adoc[*Defender as Code (DaC)*]: 用于自动资源管理的 Serverless Framework 插件。

[[key-management-transaction-execution]]
== 密钥管理和交易执行
- https://app.safe.global/[*Safe*, window=_blank]: 使用 Safe 多重签名来批准 Defender 操作。
- https://www.fireblocks.com/[*Fireblocks*, window=_blank]: 使用 Fireblocks 资产来批准 Defender 操作。
- https://www.flashbots.net/[*Flashbots*, window=_blank]: 发送私有交易，以防止 MEV 和其他攻击向量。

[[notification-and-logging]]
== 通知和日志记录
- https://www.datadoghq.com/[*Datadog*, window=_blank]: 将通知和日志推送到您的 Datadog 系统。
- https://www.pagerduty.com/[*PagerDuty*, window=_blank]: 配置 PagerDuty 以接收通知并触发操作。
- https://www.atlassian.com/software/opsgenie[*Opsgenie*, window=_blank]: 配置 Opsgenie 以接收其警报管理服务的通知。
- https://slack.com/[*Slack*, window=_blank]: 配置 Slack 频道以接收通知。
- https://telegram.org/[*Telegram*, window=_blank]: 配置 Telegram 机器人以接收通知。
- https://discord.com/[*Discord*, window=_blank]: 配置 Discord 频道以接收通知。
- *Webhooks*: 配置任何 Webhook 以完全灵活地管理任何类型的警报。
- *Email*: 通过任何电子邮件接收警报。

[[threat-detection-and-transaction-data]]
== 威胁检测和交易数据
- https://etherscan.io/[*Etherscan*, window=_blank]: 使用基于 Etherscan 的浏览器可视化来自 Defender 的交易。
- https://www.blockscout.com/[*Blockscout*, window=_blank]: 使用基于 Blockscout 的浏览器可视化来自 Defender 的交易。

[[source-code]]
== 源代码
- https://github.com/[*Github*, window=_black]: 安装我们的 xref:module/code.adoc[Code Github 应用程序]，以便在每次拉取请求时扫描您的项目，以识别潜在的漏洞并提出改进建议，以提高您的代码质量。

如果您需要任何其他集成，请 xref:index.adoc#feedback[通过 Defender 上的表格与我们联系]！
