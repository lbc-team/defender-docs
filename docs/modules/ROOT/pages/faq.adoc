[[faq]]
= 常见问题 (FAQ)

OpenZeppelin Defender 是 Defender 的进化版本，具有改进的用户体验、更简洁的界面以及提供跨 DevSecOps 生命周期更具凝聚力的体验的新功能。

== 如何注册 Defender？

新的注册已于 2025 年 6 月 30 日禁用。在 2026 年 7 月 1 日最终关闭之前，Defender 将保持完全运行，同时我们将专注于 Relayers 和 Monitor 等工具的开源版本。详细的迁移指南即将发布，以帮助您无缝过渡到开源。

https://blog.openzeppelin.com/doubling-down-on-open-source-and-phasing-out-defender[阅读更多, window=_blank]

== 迁移到 Defender 后，我还能继续使用 Defender legacy 吗？

不能，一旦您迁移到 Defender，您将无法再访问 Defender 1.0 UI 和 API。

== 迁移时是否有任何重大更改？

是的，API 端点有多个更改，需要您更新集成。您可以在 https://www.api-docs.defender.openzeppelin.com/#defender-sdk[这里, window=_blank] 找到 API 文档。

== Defender 的定价选项有哪些？

您可以在 https://www.openzeppelin.com/pricing[此处, window=_blank] 找到 Defender 的定价。

== Defender 是否提供支持？

我们为付费订阅提供服务级别和支持协议 (SLA)。在此处 xref:index.adoc#sla[了解更多]。

== 如何升级我的租户帐户？

您可以使用结算页面将您的租户帐户升级到更高级别 https://defender.openzeppelin.com/v2/#/billing/[此处, window=_blank]。

== 在哪里可以看到我的层级配额使用情况？

您可以在结算页面 https://defender.openzeppelin.com/v2/#/billing/usage[此处, window=_blank] 中查看您的层级配额使用情况。
