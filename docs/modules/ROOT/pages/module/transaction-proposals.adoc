[[transaction-proposals]]
= 交易提案

交易提案与 actions 非常相似，但您无需编写 JavaScript 代码，而是可以使用基于表单的编辑器来定义交易参数。+
这种低代码格式对于非技术用户和简单场景非常有用，但缺乏 Actions 的灵活性。如果您需要调用外部 API 或合约，或执行更复杂的逻辑，则应改用 xref:module/actions.adoc[Actions]。

[[general-information]]
== 常规信息
要从 Defender 创建交易提案，您需要定义几个参数：

* 标题：提案的描述性名称。这将稍后显示在提案列表中。
* 描述(可选)：提案的更长描述。这将显示在提案详细信息中。
* 目标合约：您要在其上运行交易的智能合约。

NOTE: 如果您在将钱包连接到 Defender 时遇到问题，如果安装了多个钱包扩展，则可能是钱包扩展之间存在冲突。

[[function]]
== 函数
定义要在目标合约上调用的函数。您可以从合约接口上可用的函数列表中进行选择。如果该函数具有参数，您可以在此处定义它们。

[[approval-process]]
== 审批流程
定义您希望如何执行交易。您可以从已配置的 Defender 中可用的任何 xref:settings.adoc#approval-processes[交易审批流程]中进行选择，或者您可以选择创建一个新的审批流程。
